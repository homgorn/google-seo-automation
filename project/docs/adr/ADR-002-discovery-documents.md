# ADR-002: Discovery Documents вместо парсинга HTML

- **Статус:** принято
- **Дата:** 2026-10-12
- **Решает:** откуда брать документацию Google API

## Контекст

Нужно автоматически получать описание API Google: эндпоинты, параметры,
OAuth-скопы, версии. Источники: HTML-документация на developers.google.com
или машиночитаемые Discovery-документы (`$discovery/rest`).

## Решение

**Discovery Documents** (`https://<service>/$discovery/rest?version=<v>`) —
единственный автоматический источник. HTML используется только для
документации, которую Google не отдаёт машиночитаемо (Merchant, Ads, Bing).

## Обоснование

| Критерий | Discovery | HTML-парсинг |
|----------|-----------|--------------|
| Стабильность формата | JSON по схеме, версионируется | Ломается при каждом редизайне |
| Парсинг | `json.loads` | CSS-селекторы, хрупко |
| Полнота | Все методы, параметры, скопы | Только то, что отрендерено |
| Скорость | 1 запрос → 166 методов | 100+ запросов |
| Частота | `revision` в ответе → детект изменений | Нет надёжного сигнала |
| Дрейф | Отдельный `revision` на каждый сервис | Непонятно, что изменилось |

Discovery-документ содержит поле `revision` (например `20261007`) — это
готовый сигнал для отслеживания изменений, без вычисления хешей вручную.

## Измеренные ограничения

Три сервиса не имеют пригодных discovery-методов (проверено 2026-10-12):

| Сервис | Состояние | Обходной путь |
|--------|-----------|---------------|
| Google Merchant API v1 | документ есть, `resources` пуст (0 методов) | proto-файлы |
| Google Ads API v18 | discovery отсутствует | GAQL из документации |
| Bing Ads API v13 | discovery отсутствует | SOAP/REST вручную |

Это ограничение источника, а не дефект парсера. Зафиксировано в
`docs/architecture.md` §2.2 и `docs/ROADMAP.md`.

## Последствия

**Плюсы**
- Одна функция `fetch_json` покрывает 7 из 10 сервисов
- Ошибки парсинга исключены как класс
- `revision` даёт бесплатный детект изменений

**Минусы**
- 3 сервиса требуют отдельного подхода
- Discovery не содержит примеров использования и рекомендаций — для этого
  остаётся ручной `wiki/api-reference.md`

## Когда пересматривать

- Google начнёт публиковать discovery для Merchant → миграция на него
- Нужны автоматически извлекаемые примеры кода → вероятно, отдельный
  парсер документации как дополнение, не замена
