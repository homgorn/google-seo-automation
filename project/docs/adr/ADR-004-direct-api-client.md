# ADR-004: Прямой google-api-python-client вместо Hyper MCP

- **Статус:** принято
- **Дата:** 2026-10-31
- **Решает:** как обращаться к Google API

## Контекст

Есть два пути доступа к Google API:

1. **Hyper MCP** — агрегированный MCP-сервер с готовыми инструментами
   (`google_analytics_ga4_reports_run`, `google_tag_manager_tags_manage`,
   `google_search_console_performance_get`, `google_ads_gaql_query`,
   `bigquery_execute_query`)
2. **Прямой клиент** — `google-api-python-client` + `google-auth` поверх
   REST/gRPC, с самостоятельным управлением credentials и квотами

## Решение

**Прямой клиент** (`google-api-python-client`). Hyper MCP не используется.

## Обоснование

| Критерий | Прямой клиент | Hyper MCP |
|----------|----------------|------------|
| Контроль над scopes | Полный — свой service account | Ограничен набором инструментов |
| Dry-run / guard-логика | Своя, в коде | Нельзя встроить в вызов |
| Аудит мутаций | Свой слой (ALLOW_MUTATIONS, cap) | Непрозрачно |
| Зависимости | 3 пакета | MCP-сервер + сеть |
| Работа в CI | ✅ self-contained | Требует подключения к MCP |
| Новые эндпоинты | Сразу доступны | Ждать обновления сервера |
| Отладка | Логи запросов свои | Прозрачный слой |

Ключевой аргумент — **принцип P3 (SPEC-001)**: любая мутация внешнего
состояния должна проходить через собственный guard (`ALLOW_MUTATIONS`,
`ADS_MAX_MUTATION_MICROS`). Через агрегированный MCP-слой этот контроль
не реализуем.

Второй аргумент — **воспроизводимость в CI**: проверка не должна зависеть
от доступности внешнего сервиса.

Решение владельца от 2026-10-31: «напрямую гугл апи».

## Последствия

**Плюсы**
- Полный контроль над аутентификацией и мутациями
- CI работает автономно
- Любой эндпоинт из discovery доступен сразу

**Минусы**
- Нужно самостоятельно управлять refresh-токенами
- Нет готовых «умных» обёрток (например, авто-выборки для Ads)
- Больше кода в проекте

## Когда пересматривать

- Появится задача, требующая агрегации многих Google-сервисов в одном
  инструменте без написания кода
- Прямой клиент перестанет покрывать нужный сценарий (например, нужен
  AdInsight без Ads API)
